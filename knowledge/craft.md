# 导演笔记：从 huashu-art-motion 蒸馏的做片纪律

> 蒸馏自 [huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion) 的 references（镜头语言 / 镜头表模板 / 正面经验 / 机制 / 纯代码绘制 / 节奏与配乐 / 视频动画语法 / 色板），按 write-video 的能力（声明元素 + s.draw + wv.wa + 配音词时间）翻译。原技能面向"用代码画艺术动画"，这份只收**换引擎也成立的做片纪律**，并标注在本技能里怎么落地。

## 一、分镜纪律：镜头表怎么写才不像 PPT

写分镜时每行四问：画面里有什么**物**（名词，能指着说"就是它"）、它在做什么**动词**、观众这一刻该看哪（镜头）、屏上几个字。写不出"物 + 动词"的那一行，说明还没想清楚，先别写代码。

五条硬规矩（写完逐条对）：

1. **开头 3 秒是一个具体的小场景**：一个人/物在做一件和题目有关的事，不是标题，不是"今天我们来讲"。第一帧就要有事发生。
2. **全片一个例子贯穿**：同一片面包、同一台机器、同一双手从头走到尾，各镜讲它身上发生的事。
3. **一镜 2–6 秒**（个别到 8 秒）。
4. **文字主导的镜头 ≤30%**：物列是标题、屏上字 7 个以上、或整镜在读字的，都算。
5. **相邻两镜换构图**：特写 → 横移 → 换物 → 换景别；换的是构图，不是画风/主题。

屏上字每镜 ≤8 字；**字写在画里的物上**（屏幕、价签、黑板、窗台），不要收在一张居中金句卡上——盲评里纯色字卡会被读成"插了一页 PPT"。本技能落地：`s.text(..., x=, y=)` 钉在画里的物上；金句收尾用 hero + 画内元素，不另起纯色底。

## 二、镜头是标点：动效怎么分配

每动一次先答三问：观众这一刻该看哪？这一下是过渡还是重音？上一个镜头的动作是什么？

**像 PPT 的根子是"每镜同一个动作"**——不管这个动作是每镜匀速淡入，还是每镜都快推一下。动作要随段落情绪变：平铺直叙时稳，转折和高潮才加快；推进去之后要有来有回。

write-video 里"镜头语言"由三样承担：

| 意图 | 本技能的做法 |
|---|---|
| 过渡（带视线走） | `wipe`/`push`/`fade` 转场 + `rise`/`slide` 入场（0.5–0.6s） |
| 重音（揭晓/数字/笑点） | `flash` + `slam`/`punch`（0.17–0.35s），一镜最多一次砸 |
| 横移/找下一件 | `push` 转场，或 `s.draw` 内部做平移 |
| 慢漂（氛围/艺术画面） | `s.draw` 内部相机（数学变换），1–4%/s |
| 停（读字/画面自己在动） | 什么都不动——静止不等于卡 |

快重音（slam/punch/flash）只给揭晓、反转、关键数字，一支片里数得过来；**不连着三镜同一种动作**。动在事件上：画面事件的 `at` 用 `a.word("词")` 对齐到配音说出那个词的时刻（本技能的词级时间戳是现成的），数字类 `s.counter` 的落定时刻 = 口播说出数值的时刻。

**入退场节奏**：入场 0.3–0.4s、退场更快（约 0.18s）、落定后要停（数字落定停 ≥0.5s，笑点后定住 ≥0.9s）。本技能入场预设自带时长，别再叠 `at` 偏移硬凑。

## 三、色板纪律：一支片一套色

- **一支片一套色板**：本技能用 `theme`（midnight/punch/light 或自定义 dict）锁全片；自定义时给 3–6 色：底、面、主字、次字、一两个强调。强调色一镜只指一个东西。
- **禁区（AI slop）**：蓝紫渐变底、深紫星空底、霓虹青紫光、紫色毛玻璃。观众一眼读成"AI 做的"。海军蓝**平涂**不算（有意图的单一底色，非渐变不发光）。
- 全片底色不亮暗来回跳；有真实素材（截图/照片）时，从素材里取一两个色当强调，底色仍用这一套。
- 要层次用纸纹、颗粒、明暗两层平涂，不用渐变底和霓虹外发光。
- 八套参考色板（键：bg/surface/ink/sub/accent/accent2，可直接写进自定义 theme）：

## 四、一屏一个焦点：解说片的版面纪律

- **先结构、后数据、最后标注**：坐标系先出、数据再长、标注最后，一镜只标一件事。
- **一屏一个焦点**：同一时刻只让一个东西入场，其余静止；主词和辅句信息量至少 3:1；背景的饱和度、对比、线宽都比主角低一档。
- **颜色＝概念**：一个颜色讲一个概念，全片语义色 ≤3–4 种。
- **真实素材当主画面**：有截图/照片/录像就满幅或占画面八九成，等比放、不裁关键 UI，代码只做标注和解释；数据只改"怎么出现"，不改"是多少"；柱一律从 0 起，轴不从 0 起要写明；虚构数据每镜标"示意数据"。本技能落地：`s.image(..., width=, zoom=)` 满幅 + Ken Burns，标注用 `s.text`/`s.list` 叠加。
- **一屏一个数时不起图表**：用 `s.counter` 大数字，在口播说出数值那一刻落定。
- 图表镜头的底和前后镜头同色系，别在深色片里突然切白底报表；更好的是把图表画进片子世界里的物（屏幕、黑板、一张纸）。

## 五、节奏与配乐：先网格，后画面

1. **先定 BPM 网格，画面与音乐都落网格上**：场景边界、转场、音效、计数落定都四舍五入到拍。本技能 `Film(bpm=)` + 场景时长按拍取整（120 BPM 一拍 0.5s）。
2. **加速靠每段变短，不靠提速**：段落时长递减（6→4→3→2 拍），BPM 不变，听感看感自然变急；结尾放长给情绪/笑点留位置。
3. **拍点那一帧必须有整屏可见的变化**：转场、入场、砸落、计数落定对齐拍点——"咔"的一声和画面顿挫是同一下。
4. **画面先定、音乐后配时，不强求统一 BPM**：逐段速度 ±8% 以内人耳听不出，但听得出换乐器没踩在重拍上。
5. **段间硬起音**：音乐段落化，段落边界不交叉淡化、不加嗖声（本技能写乐谱时段落各自起音）。
6. **结尾音效序列：停—悬—砸—反应—收**，时间点对齐画面事件帧（`film.sfx` 的 at 就是画面事件的 at）。
7. **响度对齐参考片**：本技能报告给积分 LUFS 与真峰值（目标约 -16 LUFS、真峰 ≤ -1.5 dBTP），逐段比相对差值。

## 六、s.draw 手绘纪律（画风/自绘场景）

给"用代码画一幅有艺术感的画并让它活"的管线（write-video 的 `s.draw(fn)` 路线）：

1. **五层绘制顺序**（油画/版画类默认，水墨/图案类例外）：平涂底稿（定构图明暗）→ 风格渲染器整幅重画 → 小物件单独一层（混在大面积里会被打碎）→ 主体/角色层 → 会动的高光。
2. **区域色板 > 颜色抖动**：每个区域给 7–8 色的色组，每一笔从组里抽色，再混 30–45% 底稿色保留明暗。只做颜色抖动 = "同一个蓝的噪点"。
3. **材料的物理过程就是渲染器**：写渲染器前先问"这种画在现实里怎么做的"——套色木版 = 填色相对墨线错位；马赛克 = 石块沿轮廓排、颜色每帧流过；像素 = 低分辨率逐像素 + 1px 黑边；明暗法 = 先画亮版再乘光照图。
4. **每幕 = 主动作 + 2–4 个母题小循环**：画面要一直活，但动的东西要在视线焦点上；自检运动量用两帧帧差（避开转场后 0.35s）。
5. **大面积沸腾换种 = 闪，不是活**：整屏按 8fps 重洗颜色的帧差比转场还大，审片读成"画在闪"。笔触位置固定、让方向场随时间连续摇曳（火苗般）；色板换种用相邻种子色做缓动渐变；沸腾只留给线稿。
6. **小东西画得比直觉大 1.4–1.5 倍**：22–50px 读不出，44–74px 才读得出。
7. **一切随机用种子**，同一时刻渲两次逐像素一致（本技能 `c.rand(i)` 已保证）；**静态部分缓存**，每帧只画会动的（`make_bg()` 预渲染 + `paste_full` 模式）。
8. **转场 = 下一个风格的签名语言**：换风格/换章节的转场从"新风格最有辨识度的形式元素"里长出来（从画内物体生长、从无到满），不从通用转场库里挑。本技能转场有限（cut/fade/flash/wipe/push/zoom），签名感靠 `s.draw` 在转场前后画"新章节的母题"。

## 七、审片纪律：查画面，也查口径

- **交付前派一个没参与制作的审片（或自己隔一小时只用观众视角看成片）**：制作者看三轮都发现不了的问题， fresh eyes 一遍就抓到。
- **查逻辑和数字口径，不只查画面**：实测抓到过的错——"涨了 8.7 倍"应为"涨到 8.7 倍"；讲 A 却连到 B；两处数字对不上。画面完美、内容错最伤可信度。
- **验收工具也要被验收**：每个检查项故意制造一次失败（删一个场景、写错一个音效名），确认它真的会红。
- 本技能的自动检查（lint / 闪烁 / 响度）之外，人工清单：文案逐字、命中时刻、招牌镜头到位、数字口径、色板一致性。
