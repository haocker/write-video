# write-video · 阶段 1：策划

目标：把「想要一个视频」变成用户确认过的**简报 + 分镜**，写进项目 HANDOFF.md。
策划阶段不写影片脚本、不渲整片（用户同意时可以渲一两帧样张帮他选风格）。

## 流程

1. 建项目目录：`<项目名>/`，新建 `HANDOFF.md`（可选：`res/` 放素材、`artifacts/` 放产物）。
2. 收集：用户已给的信息先用上；缺的按下表问——一次只问一两个最影响方向的问题，其余先用默认值并说明可改。用户给的文章、网址、截图就是原料，自己读，别让用户复述。
3. 写简报与分镜（格式见下），把分镜表和三句话概要（讲什么、怎么讲、多长）发给用户，请他确认或指出要改的地方。
4. 按反馈修订直到确认 → HANDOFF 阶段改为「策划已确认」→ 进入编排阶段。

## 要定的事（按影响排序）

| 事项 | 为什么 | 没说时 |
|---|---|---|
| 用途与观众：在哪发、给谁看、看完做什么 | 决定规格、节奏、结尾的行动号召 | 问 |
| 核心信息（一句话） | 每个场景都为它服务 | 从用户材料提炼一句，请用户确认 |
| 必须出现的内容：卖点、数字、网址、logo、截图 | 分镜的原料 | 问 |
| 规格：横竖、时长 | 横竖屏版式完全不同 | 短视频平台（抖音/视频号/小红书）1080×1920；网站/B 站/发布会 1920×1080；15~30 秒 |
| 风格：主题、节奏、配乐 | 第一眼的感觉 | midnight + 120 BPM + tech |
| **招牌镜头**：这支片独有、只能自绘的画面是什么 | 内容型画面（文字、清单、数字、截图）每支片都一样；让片子有记忆点的是它 | 必答。用户没想法时 AI 按核心信息提 1~2 个方案请用户选 |
| 素材 | 有真素材才有说服力 | 缺图时：draw 自绘（图表、示意图）；背景/氛围图可以文生图；logo 用真实文件 |
| 交付 | 文件名、要几个版本 | `artifacts/<项目名>.mp4`，一个版本 |

风格用描述让用户选，不要让他记名字：

- 主题：midnight 深蓝 + 青（科技产品）；punch 黑 + 黄（快剪、强节奏）；light 浅底 + 蓝（简洁正式）。
- 节奏：90 BPM 舒缓，120 标准（一拍 0.5 秒），140 激烈。
- 配乐：tech 科技律动，upbeat 欢快，ambient 沉静叙事，lofi 轻松日常；或不要配乐；也可在编排阶段自定义调性与旋律（见 compose.md）。

## 分镜写法

一行一个场景。时间写**成片秒数**（全局时钟，脚本里就是这个数），场景首尾相接、落在拍上；
屏幕文字写**最终文案**（编排时逐字照抄）；画面用下面「镜头菜单」的说法，招牌镜头标【招牌】
并写清画面里的事件（撞击、划线、点亮……编排时就是它的时刻表）；声音一般写「自动」，
特殊的才写（如命中前加 riser 蓄力）。

| # | 时间（秒） | 画面与动作 | 屏幕文字 | 声音 | 转场 |
|---|---|---|---|---|---|
| 1 | 0–4 | 品牌名 slam 砸下（1 秒落地），副标题逐字浮现 | aardio / 小巧、快速、原生 | riser 蓄力 → 自动 | — |
| 2 | 4–6 | 快剪：每拍一个卖点 | 下载即用 / 一键生成 EXE | 自动 | cut |
| 3 | 6–12 | 标题在上，清单逐条滑入（✓ 图标） | 一个语言，**桌面全能** | 自动 | wipe |
| 4 | 12–15 | 【招牌】光环沿 logo 轮廓画出，12.8 秒闭合迸出火花 | — | 闭合处 impact | fade |

## 镜头菜单（都是现成能力）

| 想要的效果 | 做法 |
|---|---|
| 品牌/标题砸下，震屏 | text style="hero" enter="slam"（提前 0.3 秒起跳，不要放在场景第 0 秒） |
| 一拍一词快剪 | 每拍一个场景 + enter="punch" |
| 副标题逐字浮现 | split="char" |
| 金句逐行弹出，重点词变色 | split="line" + `**重点**` 用强调色 |
| 卖点清单逐条滑入 | list + icon（check、star、dot、rocket…） |
| 数字滚动（滴答…叮） | counter，格式如 "%d 颗星"、"%.1f MB" |
| 截图/照片展示 | image（圆角 radius） |
| 代码/终端特写 | text font="mono" enter="type"，或用 draw 自绘终端卡 |
| logo 弹出 + 星光 | image + burst("sparkle", on=logo) |
| 网址、口号打字 | text enter="type" |
| 说明文字、脚注 | caption 样式 |
| 图表、时间轴、流程图、示意动画、招牌镜头 | draw 自绘（canvas 绘制，动画按时间 t 写） |
| 转场 | cut 默认；fade 柔和；flash 白闪重音；wipe 换章节；push / zoom |

还不能做（通用版 v1）：真人/实拍、口型、外部音频与配音、序列帧、逐词出字。

## 节奏与文案

- 钩子：前 1~3 秒放最强的画面或最抓人的一句。
- 一个视频一个核心信息，一个场景一句话；数字要具体，并且能被画面证实（说「240 颗星」就真画 240 颗）。
- 阅读时间：中文约 6 字/秒；屏幕上一句 ≤12 字（竖屏）/ ≤18 字（横屏）；停留 ≥ 字数÷6 + 0.5 秒。
- 快慢交替：快剪（一拍一场景）之后接 2~4 秒的阅读场景；结尾留 ≥2 秒。
- 量：横屏 20 秒通常 5~7 个段落；竖屏 15 秒 5 个左右。内容多就加长或拆成两条，别堆字。

## 结构模板

- 15 秒竖屏：0–3 钩子快剪 → 3–7 核心句 → 7–11 证据（清单或数字）→ 11–15 品牌 + 行动号召。
- 20~30 秒宣传：品牌 slam → 卖点快剪 → 功能清单 → 数字/截图 → logo + 网址。
- 30~60 秒演示：标题 → 步骤 → 结果对比 → 结尾卡。
