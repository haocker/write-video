# write-video 升级路线图

> 依据：2026-10 会话中 5 部成片（尊界解读 66s、token 教程 80s、v6 宣传 47s、艺术宣传片 47s、hello-world 两版）的开发实录。
> 每个方向的"动机"都是会话中真实发生过的成本，不是设想。

## 现状（v0.4.x）

- 声明式场景：scene / text / list / counter / image / draw / audio / music / sfx
- 词级对齐配音（a.word()）+ 配音驱动场景自动扩展 + 自动配乐（手写乐谱）
- lint 管线：超界、阅读时间、单帧闪烁、场景开头空白、词缺失、联系表
- 捆绑字体 4 款（优设标题黑 / 字体圈伟君黑 / 字制区喜脉体 / 文泉驿等宽微米黑），零系统依赖
- craft.md 导演笔记 + 7 条分镜硬规矩

## P0 补短板（下一批片就能回本）

### 1. 自绘图元库 primitives

- **动机**：5 部片手写了 20+ 个 draw 函数——踏板受力、车速表、墨点阵、音条、光弧、终端卡、检验章、进度条……全是手搓几何 + 缓动 + 呼吸样板；PIL 后端零宽 rect 崩溃也是手搓暴露的
- **方案**：runtime 新增 `write_video/shapes.py` 高层图元：`gauge` / `chart_line` / `bar_visualizer` / `terminal_card` / `stat_card` / `badge` / `arrow` / `beam_sweep` / `particle_swarm` / `progress_bar`。统一呼吸式动效、缓动、亚像素安全
- **验收**：同类片的 draw 代码量减半；零宽/负尺寸崩溃在图元层不可能发生

### 2. 词对齐工作流

- **动机**：每片都要先跑 gen_voice.py 打印 token 再手抄进 film.py；词猜错就 lint error 拒渲染重来
- **方案**：`a.word_or(key, fallback)` 带兜底查找（词不存在 → lint warn + 用 fallback 秒数，不再拒绝渲染）；`wv.voice.plan(texts)` 一键打印 token 表（现 gen_voice 脚本进 runtime）
- **验收**：新片省掉 gen_voice 预跑步骤；错词降级为 warn

### 3. 闪烁自动归因

- **动机**：三次闪烁（踏板回程、瞬间冲击阶跃、音条边缘）都是渲条带 + 看图 + 人工猜元素；音条边缘那次还误判过
- **方案**：渲染时记录每元素逐帧 bbox + 内容哈希，flicker 事件反查"该像素附近哪些元素有状态跳变"，lint 消息直接报元素与原因（边缘运动 / 回绕跳变 / 帧丢失）
- **验收**：不用渲条带就能区分"设计意图"与"真 bug"

### 4. 双后端一致性 ✅（2026-10-14 已完成，方案调整为"混合后端"）

- **动机**：同一脚本 PIL 后端零宽 rect 崩、skia 后端 `max(1,...)` 静默——两个后端语义不同
- **落地**（`3e9f1b3`）：默认后端改为 **PIL + skia 混合**——曲线类图元（polygon/circle/ellipse/arc）画到帧级复用的 skia 抗锯齿覆盖层（惰性创建 + 脏区回写 + 按 alpha 合成），矩形/线/文字仍走 PIL；修 skia parse_color 主题色崩溃；skia 后端作为独立后端保留（canvas_skia_full.py）
- **实测**：笔触帧暖态 0.53s → 0.35s（-34%）；月牙/曲线边缘锯齿消失
- **遗留**：golden-frame 测试仍值得加（防两套路径漂移）；`WV_AA=0` 可关 skia 回退纯 PIL

## P1 放大优势

### 5. 多画幅与多格式导出

- **动机**：成片全是 16:9；用户要过 SVG 分镜版（目前是项目内脚本）；视频号/抖音要 9:16
- **方案**：`Film(canvas="9:16")` + pos 语义自适应；runtime 内置 `film.export_svg()`（吸收 make_svg 原型）、GIF 预览、SRT 字幕导出
- **验收**：同一脚本切画幅重渲即可用

### 6. 乐谱模板库

- **动机**：make_score 在 4 部片里复制了 4 份，只改和弦和密度
- **方案**：`wv.music.score("cinematic-minor" / "bright-major" / "tense", duration, bpm)`，内置 5-6 套情绪模板（进行、配器、密度、淡出可覆盖）
- **验收**：music 三行变一行

### 7. 素材管线

- **动机**：image 元素存在但 5 部片没用过——真实截图/LOGO 进片缺 ken-burns、圆角卡、遮罩
- **方案**：image 增强：fit/cover、圆角、慢推慢移、淡入淡出；标准"截图卡"组件
- **验收**：产品介绍片能插真实截图并有电影感动效

### 8. 渲染性能

- **动机**：47s 片渲 2-2.5 分钟；每次改一行都要全量重渲
- **方案**：帧级 multiprocessing 并行、音频合成缓存、`film.render(from_s, to_s)` 增量渲染
- **验收**：47s 片 200% CPU 下 < 60s

## P2 探索

### 9. 分镜 DSL 与大纲起草

- **动机**：HANDOFF 分镜表是手写 markdown，翻成 film.py 靠人肉
- **方案**：结构化分镜（yaml：镜号/时长/屏上字/画/声）→ `wv.draft(storyboard.yaml)` 生成 film.py 骨架（占位元素 + 词位标记）
- **验收**：口播片从大纲到可渲骨架 < 5 分钟

### 10. AI 素材桥

- **动机**：v6 文案自己就说"AI 生成还不可控"——确定性渲染 + AI 局部素材是互补而不是二选一
- **方案**：image 场景接外部生图（用户提供的图或 API），write-video 负责编排、运镜、字幕的确定性
- **验收**：一张 AI 海报进片自动 ken-burns + 词对齐字幕

### 11. 数字口径 lint

- **动机**：新闻解读片靠人工核对"配音数字 = 屏上数字 = 来源"
- **方案**：lint 校验配音文本中的数字必须出现在该场景屏上字或来源行，反之亦然
- **验收**：数字口径错误渲染前被抓

### 12. 交互式预览

- **动机**：审片只能整片播放或抽帧
- **方案**：`film.export_preview()` 出 HTML：时间轴 + 分镜缩略 + 词表，点词跳帧、点镜跳段
- **验收**：改一处后秒级定位到变化镜头
