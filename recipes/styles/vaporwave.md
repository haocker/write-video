- 同族: sy-styles-20 styles/12-synthwave，融合时择优
- 来源: huashu 风格配方 26_vaporwave.md
- 层次: 材料层
- 质量: ★★★ ；短板: 部件交界也发光（霓虹线稿能接受；要纯外轮廓需先把剪影画进离屏再描离屏边缘）

## 核心渲染器与手法

1. **管线**：整幅先画进离屏 S，再做 VHS 后期输出到 c（计数器由引擎画在最上层，不受色差影响）。
2. **墙**：深紫纵向渐变 `#0d0322 → #4a0f6a` ＋窗口处洋红径向光、招牌处青色径向光；墙脚一条青色灯带。
3. **`glowLine(c, col, w, blur)` 霓虹灯管**：同一路径先用 shadowBlur 描粗的辉光，再描 2–3px 近白芯线。
4. **窗里落日**：太阳是黄→橙→洋红竖向渐变，用 destination-out 切 7 条横缝（缝宽随深度变大 2 + q²·16），整体以 0.9/s 上移；地平线是线框山（洋红辉光），下面青色透视网格往观众方向滚，左右棕榈剪影摇。
5. **地面网格**：洋红透视网格，消失点 (960,600)，横线 `y = 600 + 520/d`、d = k + 1 − phase（phase = 1.3t mod 1），线宽随近处加粗。
6. **霓虹招牌「カフェ」用折线自己画灯管**（不依赖字体）：每个假名 1–3 笔，(u,v) 单位坐标；逐字按帧哈希闪 `hash(floor(30t), k) < 0.07` 灭；「フ」额外在 `f mod 17 < 5` 时 22% 概率灭，灭时画暗紫灯管。
7. **Win95 对话框 TEA.EXE**：灰体、海军蓝渐变标题栏、进度块 `3 + 14lt` 格、百分比 `18 + 70lt`；桌上大理石胸像（侧脸剪影 22 点、紫灰渐变＋静脉线＋粉色轮廓光＋墨镜梗）。
8. **角色辉光轮廓**：朝窗一侧粉、背面青——同一组路径描两次，分别 clip 在左右半屏。上衣用薰衣草紫风衣 `#8f7cf6`＋白三角领＋青色拉链线。坑：上衣第一版是粉色，和粉调肤色混成一片，读起来像没穿衣服。
9. **VHS 后期 `vhs(c, S, t, lt)`**：RGB 分离——对每通道把 S 画进临时画布、multiply 纯色 `#ff0000/#00ff00/#0000ff` 取出单通道，再以 lighter 错位合成到黑底（错位量 3 + 1.5sin(7t)，偶发 hash<0.12 时 +6）；跟踪噪声带 70px 高、`(520lt + 200) mod (H+160)` 下滚，带内每 6px 一条横向错位 `±30·sin(πy/bh)`、叠 90 条白灰噪线；扫描线 4×4 tile pattern（第 0 行 α 0.28、第 2 行 α 0.12）；OSD：PressStart2P「PLAY」＋手画 ▶（字体里没有这个字形），16 帧一闪，左下日期、时间码按 lt 走。
10. **色板与字体坑**：洋红 `#ff4fd8`、热粉 `#ff2f8f`、青 `#3ff6ff`、深紫 `#12052a / #2a0b4a`、日黄 `#ffd84a`、橙 `#ff8a3a`。坑：全角「ＶＡＰＯＲＷＡＶＥ」、▶、日文在 lib/fonts 里都没有，会静默回退系统字体——标签改用半角＋字距 7，▶ 和假名都自己画。

wv 对应: post_cinema（ca 色散≈RGB 分离、确定性颗粒）；需新渲染器（VHS 跟踪噪声带、扫描线、glowLine 双层描边霓虹）；透视网格、落日、对话框、假名灯管用图元直绘（gradient/polygon/rect/text）

## 母题动作

- 落日横条 0.9/s 上移，缝宽 `2 + q²·16`
- 网格前滚：phase = 1.3t mod 1，横线 `y = 600 + 520/d`
- 招牌假名闪：`hash(floor(30t), k) < 0.07`；「フ」`f mod 17 < 5` 时 22% 灭
- 跟踪噪声带下滚：`(520lt + 200) mod (H+160)`，带内横向错位 `±30·sin(πy/bh)`
- RGB 错位 `3 + 1.5sin(7t)`，偶发 +6；棕榈剪影摇

## 签名转场

VHS 撕裂＋上滚（跟踪噪声带把画面撕开带走）

## 性能

每帧中位 49ms；帧差 25%（VHS 后期让全屏都在动，属预期）；实验文件约 210 行。
