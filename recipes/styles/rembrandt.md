# rembrandt · 伦勃朗明暗法 1642 · 光照图整幅相乘的昏暗油画

- 来源: huashu 风格配方 32_rembrandt.md
- 层次: 材料层
- 质量: ★ ；短板: 人物扁平（审片 5/10），最该重做

## 核心渲染器与手法
- 管线：亮态底稿（按「全亮」颜色画房间、铅条菱格窗、土耳其桌毯）→ 褐色大笔触重画背景＋糊 2.2px 叠 75%（揉开的底子）→ 桌毯单独一层细笔触 → 角色平涂＋体积渐变＋细笔触 → 角色失边 → 光照图 multiply → 窗玻璃 screen 提亮＋云影掠过 → 鬃毛厚涂 → 烛焰、光柱浮尘、热气 → 龟裂、颗粒、暗角＋soft-light 金褐釉。
- 光照图：底色 rgb(30,21,13)（环境光 0.13），lighter 叠楔形光柱（模糊 40px、缓存、α0.8–0.95）、窗本身 r330、脸池 r250 α0.95、胸 r230 α0.55、猫 r240 α0.8、桌面 r280 α0.6、烛光 r190+40·fc α0.6+0.4·fc、少女暗侧背后「分离光」r300 α0.35（伦勃朗惯用，把人从背景分出来），最后整幅 multiply。
- 摇曳：flick(t)=0.5·noise(2.2t)+0.25·noise(6.5t)；光池中心随 noise(0.9t) 漂移 ±14px；云影 cloud=0.5+0.5·sin(2.2t−0.6) 让窗光 ×(1−0.35·cloud)，一团暗色径向斑以 260px/s 横穿玻璃。
- 背景笔触：cell18、len54、w16、jitter 6、角度 −0.9+1.6·noise(0.003)、色板 mixBase 0.7。道具单独成层画在笔触之后——拷回原图局部区域（drawImage 取块）会把未刷笔触的背景一起带回，形成矩形补丁。
- 失边：角色层先 blur(2.4px) 全不透明画一遍，再叠 α0.62 清晰层；暗侧融进背景，五官仍认得出。
- 厚涂鬃毛笔：一笔 = round(w/1.3) 条平行细鬃，每条亮度 ±17、两端随机缩 0–25%、线宽 1.4–2.6；下侧 α0.28 投影，上侧撒 2+w/3 个亮点。只用在受光处（金发、领口、瓷杯、珍珠、猫白胸、猫头顶）。坑：第一版画成「暗影偏移＋主笔＋亮脊」三条整齐的线，读成白色贴纸/创可贴，改成鬃毛笔才像颜料。
- 罩层：龟裂 α0.28×0.28；颗粒 density 0.05 α0.12（0.12/0.22 会让脸上全是脏点）；暗角 0.75；soft-light rgba(200,140,60,.35)。
- 顺序坑：手要在杯子之前画（drawGirl 里是「手→杯→拇指」），否则手的椭圆盖掉瓷杯。
- wv 对应: dabs（背景笔触底子）＋ texture（龟裂/颗粒/暗角）＋ 图元直绘（gradient 光照图 multiply、screen 窗光）＋ post_cinema（soft-light 罩层）

## 母题动作
- 烛焰：noise 驱动左右倾、高度跳。
- 窗光被云影遮暗再恢复；光柱里 70 颗浮尘只在光柱内显示、24 帧闪烁。
- 端杯；热气。运动面积 8.0%（0.45↔1.0s）。

## 签名转场
- irisFilm 0.5s（迁移测试 D，伦勃朗→橡皮管；本卡旧画被收进光圈）：p<0.5 旧画逐步加 sepia(q) grayscale(0.7q) contrast(1+0.3q)，黑色光圈收到杯口 (1236,420)，R=R0·(1−easeIn(q))，R0 取最远角距离；p≥0.5 新画按 R0·outBack(q) 弹开；圆周 48 段按 12fps 加 ±1.5% 手抖；全程叠胶片闪烁、划痕、灰尘。
