# 3d-render · 3D 渲染 · 粉彩摄影棚里糖果方块搭领奖台，金环像欧拉盘转着落定，玻璃珠滚过、镜面球登顶

- 来源: sy-styles-20 styles/05-3d（MIT, 肖雄）
- 层次: sy 实用风格
- 技术: WebGL 光线步进（Reel.RM 封装，含 bloom/DoF 后期）
- wv 可移植性: 不可移植（3D 光线步进 + 物理材质 + 屏幕空间 DoF 都是 WebGL 专属；编排公式和音效节拍可借鉴）

## 核心手法

- 场景：粉彩 cyc 背景（后墙距 3.4、圆角 1.9 的 sdCyc），3 块糖果方块（黄/粉/青 COLS=(1,.66,.1)/(.98,.24,.46)/(.12,.6,.92)，sdRoundBox 圆角 .12，落地 squash 绕底面压缩 q.y/=sq、q.xz*=sqrt(sq)），铬球 r=0.36，金环 R=0.36/r=0.075，2 颗玻璃珠。
- 打光：主光 LDIR=(-0.55,.82,.5)；软阴影 32 步（玻璃透光 k=0.6）；AO 5 层采样；焦散=玻璃珠后方 exp(-(dperp/(r*.32))²)*2.2；环境反射 envRefl=粉墙+主 softbox（×13）+冷色条灯（×4）+黑旗（-0.82 负补光，让金属读出金属）。
- 材质：糖果块 wrap 漫射（wrap=(dot+.35)/1.35）+清漆 schlick F0=.045（F>.07 才真反弹 trace1，否则直接 envRefl）+法线微面噪声；铬/金 F0=(.96,.95,.93)/(1,.76,.33)，金加 0.25 拉丝混 envRefl；玻璃=反射+折射 1/1.52，球内出口解析求交，全内反射回退 reflect。
- 后期（RM 参数）：bloom 0.24 / th 1.3 / expo 0.95 / vig 0.32 / grain 0.022 / ca 0.35 / contrast 1.08 / sat 1.08 / bands 8；DoF 走 rm.render({focus, aperture, maxCoc:14})，焦点=相机到注视点距离。
- 编排公式：drop(t,t0,h0,e=0.36,g=30) 自由落体+弹跳（每次 v*=e）+落地 squash 冲量 imp=0.22exp(-(dt/0.055)²)；金环 2.5-3.4s 直立滚入，3.4-5.7s 欧拉盘螺旋倒下 tilt=1.36(1-u)^0.62、进动积分 dphi~2.4/sqrt(tilt) 加速，落平后 rattle=0.035exp(-w*7)|sin(w*30)|。
- 相机：Catmull-Rom 6 键（位置+注视点+光圈），手持抖动 hx=0.01sin(t*1.1)。
- wv 对应: 不可移植（3D 光线步进/WebGL 专属）；可移植的是编排层——drop() 弹跳公式、欧拉盘进动、Catmull-Rom 运镜、cue 节拍

## 母题动画与钩子

- 0.45/1.2/1.95s 三块方块依次砸落搭领奖台（thud ×3），2.55s 金环滚入；钩子在 3.4-5.7s：欧拉盘旋转倒下（clink 5.7 落定），5.75s 铬球最后登顶，玻璃珠 3.0/3.55s 滚过。
- cues: thud 0.82·1.57·2.42 / roll 2.55 / clink 3.4·5.7·6.22 / whoosh 6.0 / swell 7.0。
