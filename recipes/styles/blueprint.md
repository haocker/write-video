# blueprint · 蓝图工程图 · 爆炸图扫描线一过图纸变成真实产品

> wv 样片：已移植·降级（raymarch 换 2.5D 假投影，样片 examples/style-ports/blueprint/film.py）

- 层次: 实用风格
- 技术: 光线步进 3D（轮廓线由 raymarcher 自身找出）+ 2D overlay 标注层
- wv 可移植性: 不可移植（3D 依赖）——轮廓/折痕线靠 raymarch 近失跟踪；2D 标注层（尺寸线/引线/标题栏）可直接移植

## 核心手法
- 播客麦克风 6 个零件沿 y 爆炸：网罩 +.95e、卡口环 +.5e、Y 形架 -.28e（臂 ±(.6+.38e)）、立杆 -.62e、底座 -1.05e；3.85-5.05s 组装，到位加微震 .02exp(-9Δt)·sin(40Δt)。
- **轮廓线由 raymarcher 找**：步进时记录近失量 w=h.x/(t·px) 的最小值；未命中或命中点远在近失点之后（h.x-gapT>.25）→ 剪影线 smoothstep(1.7,.55,w)；折痕线＝命中点法线与两侧偏移点法线的最小夹角 cr=min(dot(n,nrm(p±tA·o))) smoothstep(.93,.7,cr)；网罩再叠细环 fract(yy/.09)。
- 图纸绘制感：uReveal 自上而下擦入 smoothstep(uReveal, uReveal-.35, xr)，前沿加绘图仪辉光 tip=exp(-((xr-uReveal+.12)/.1)²) 加色 (0.6,1,2.2)。
- 蓝图纸：深蓝渐变＋细格 uRes.y/54 与粗格 /10.8 双层线＋fbm 纸面不匀。
- **扫描线变身**（5.25-6.55s）：逐像素 edge=uScan-sy，±.004 内 mix 蓝图→实物；扫描线本体 2.6exp(-(edge/.0035)²) 加 (.45,.8,1) 辉光＋下方 .05 衰减拖尾。2D 标注层同步 clip 到扫描线以上。
- 实物材质：网罩＝极坐标网格 (atan·30/π, y/.03) 半格错位挖孔露出黑腔；铬环 env×schlick(.5)；机身哑光黑 .025；拉丝铭牌 sin(lp.x·900)；旋钮滚花 sin(atan·60)。地面反射 .16 衰减＋32 步软影＋AO。
- 2D 标注：引线＝锚点圆点→肘弯→r22 编号圆圈（等宽字体）；尺寸线从中间向两端生长 E.outCubic＋16px 箭头，文字「Ø88」「462→286」；中心轴虚线 [34,8,4,8]。
- 标题栏 520×132（DWG. NO. XX-2026-020 / SCALE 1:2 / DRAWN  / DATE），线色 #eaf3ff，随 uReveal 一起淡入。

wv 对应: 不可移植（3D 光线步进专属）；引线/尺寸线/标题栏/中心轴是纯 2D 图元直绘，配 2.5D 假投影可整体移植

## 母题动画与钩子
- 节拍：0.35-2.7s 图纸自上而下画出＋引线逐条弹出（错 0.22s）→ 2.6-3.4s 尺寸标注 → 3.85-5.05s 零件组装（钩子之一）→ **5.25-6.55s 扫描线扫过图纸变实物（钩子时刻）**→ 7.0-8.6s 扫光棒掠过成品 → 7.2s「从图纸 到实物」字幕。
- 音效：pen/tick×3/whoosh/clink/data/swell/sparkle。

## 签名转场/镜头
单机位缓移（yaw .62→-.18，dist 12.6→8.4），t>6 才开景深；"扫描线"既是特效也是转场——线上是图纸、线下是实物。
