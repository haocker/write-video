# picasso_blue · 毕加索蓝色时期 1903 · 全蓝单色＋普鲁士蓝粗轮廓的忧郁油画

- 层次: 时代标本
- 质量: ★★ ；短板: 造型不够忧郁

## 核心渲染器与手法
- 管线：蓝单色平涂底稿（墙、地、窗外夜海和月亮）→ 宽而干的笔触重画＋糊 7px 叠 80% → 极淡的干刷细丝 → 窗框原样拷回＋小笔触 → 桌单独一层 → 环境粗轮廓（不抖）→ 海浪、月光碎影、云 → 角色（整体拉长）→ 角色小笔触＋冷光渐变 → visibleLines 粗轮廓 → 披肩褶线 → 慢热气 → 画布纹＋冷暗角。
- 色板严格单色：#132240 / #1d3866 / #2d5a94 / #6b8fb6 / #b6c8d8 / 青灰 #3b6878。橘白猫用明度区分：橘＝中蓝 #4f719a、虎斑 #273f66、白＝浅蓝 #b6c8d8；金发＝最亮蓝灰 #cbd8e0、肤色 #90a9be，发色要比肤色亮一档才读得出「金」。坑：第一版给猫和头发留了赭色（想参考《老吉他手》），独立审片判定破坏单色——蓝色时期就该全蓝。
- 墙笔触：cell34、len110、w34、jitter 4、竖向 ±0.5·noise(0.003)、色板 mixBase 0.8，之后 blur 7px 叠 α0.8；地面同参横向。坑：cell16、len40、w14 满墙竖刷读成「下雨/毛毯」（印象派），要宽、长、低对比再糊一层；宽笔圆头密排成「人头阵」，用糊 7px 压住，根治要给 strokes 加 cap 参数。
- 拉长：少女 DOMMatrix().translate(1240,932).scale(0.84,1.12) 以脚底为轴；猫 scale(0.82,1.14) 以 (540,905) 为轴；同一矩阵用在三处（Path2D.addPath、离屏 setTransform、visibleLines 回调里的 setTransform）。
- 披肩：从 forehead/headTop 罩下，经 nape、back 落到 waist+70，色 #6b8fb6，褶线 rgba(20,40,80,.6) 4px；长指：3 个细长椭圆 22×4.5 绕杯。
- 轮廓：普鲁士蓝 #0c1830、5px、不沸腾——蓝色时期的轮廓线是笃定的。
- 慢节奏：呼吸 sin(1.8t)·0.026（幅度约为共享编舞 2 倍、频率约 0.45 倍）；端杯 1.25s 举起（共享编舞 0.9s）；热气按 0.5 倍时间升。
- 桌子坑：用矩形 mask 把桌子排除在大笔触之外，地面会留一块平涂矩形补丁——桌子要单独成层画在笔触之后，不在笔触里挖洞。
- wv 对应: dabs（宽干笔触底子＋干刷细丝）＋ texture（画布纹/暗角）＋ 图元直绘（gradient 冷光、海浪）＋ 手绘管线（需补 cap 参数根治圆头密排）

## 母题动作
- 窗外海浪横移：越近越快，速度 20+0.25·(y−400)。
- 月光碎影 14 条闪烁；一条苍白长云横过月亮。
- 缓慢呼吸（人和猫）；端杯；热气。运动面积 3.2%。

## 签名转场
- blueBrush（迁移测试 D，新海诚→蓝色时期，本卡为新画）：①旧画 color 混合叠 rgba(45,90,148, min(1,2.2p)) 只剩蓝，再 multiply 压暗 ②6 道宽笔（每道高 H/6+90）交错倾斜 ±18 依次从左刷到右，启动时间错开 0.07，笔头是一段二次曲线、上下边带 6–7px 正弦抖动 ③笔头后 80–280px 内有 26 条深/浅渐变鬃毛线（颜料还没刷匀）。
