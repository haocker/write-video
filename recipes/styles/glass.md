# glass · 弥散渐变 玻璃拟态 · 极光壁纸做锁屏，玻璃卡片从药丸里长出来，玻璃球掠过时钟真实折射色散

- 来源: sy-styles-20 styles/10-glass（MIT, 肖雄）
- 层次: sy 实用风格
- 技术: Canvas 2D 壁纸 + WebGL 玻璃（2D SDF 折射）
- wv 可移植性: 部分可移植——壁纸/时钟/渐变/UI 直接可移植；玻璃折射（SDF 法线+透镜弯曲+RGB 色散）需 WebGL pass

## 核心手法

- 双层结构：底层 2D 画布画壁纸——基色 #070726→#140a3c→#22072e，5 团 aurora 光斑（screen 混合，漂移 sin(t*0.35)），3 条 blur(18px) 极光带，80px 细网格 + 70 颗星（给玻璃留可弯折的锐利内容），430px Inter Display 巨钟，字幕直接写进壁纸让玻璃也把它折弯；上传成纹理。上层 WebGL 全屏玻璃 pass。
- 玻璃 SDF：8 个形状=圆角矩形 sdRR（中心/半宽高/圆角/融合 k/雾度/倒角），形状间 smin(k) 平滑融合或 min 硬接；每形状独立 frost/bevel，按距离权重插值。
- 折射：法线=SDF 梯度（e=1px 差分）；透镜倒角 bend=min(Rb,40)*1.5*(1-tt)^2.4 在边缘最强（tt=clamp(-d/Rb)），全表面再恒定放大 -3px；放大镜球 off=-oq*0.45*(1-orr²)（中间放大、边缘压缩）；RGB 色散 disp=0.09*(1-tt)^1.4，三通道按不同偏移采样。
- 毛玻璃：frost>0 时 12 点黄金角螺旋采样平均（golden angle 2.39996）。
- 玻璃质感：奶白 0.025 + 整体增亮 1.06、sheen=pow(1-tt,3) 边缘亮环、下缘内阴影 -0.22、上缘高光；镜面棱线：主光 L=(-0.6,-0.8)，rim1=smoothstep(2.6,.2,|d+1.4|) 内缘亮线 + 对侧弱棱；投影=SDF 下移 18px，col*=1-0.2exp(-ds/30)。
- 编排：灵动岛药丸 spring(140,13) 落下 → 1.5s 胀成音乐卡（170→800 × 50→190）；播放键 2.5s 落下、3.25s 裂成三颗（sep=185）；玻璃珠 4.2s 从播放键拉出、掠过时钟当放大镜（r 40→150）、7.0-7.4s 归位；音量条 7.1s 长出、玻璃珠随速度拉伸（28*(1+0.55vel)）。
- UI：卡片渐变图标 #ff6fb5→#ffb347→#6a5cff、26 条均衡器 sin(t*5)、播放/暂停图标切换。
- wv 对应: 图元直绘（壁纸/时钟/渐变/UI）+ 需新渲染器（2D SDF 折射 pass：法线差分、透镜倒角、RGB 色散、黄金角采样毛玻璃）

## 母题动画与钩子

- 0.3s 药丸 blob 落下，1.5s expand 长成音乐卡；钩子在 4.2-7.4s：玻璃珠被拉出掠过巨钟，时钟数字在球里真实放大、边缘色散，再落回播放键里。
- cues: blob 0.3 / expand 1.5 / blob 2.55 / stretch 3.25·4.25 / whoosh 4.9 / blob 7.45 / stretch 7.6 / chime 8.2。
