# lineart · 线条动画 · 九百根金色细线如丝绸随风飘，再排成透视山脊，一束光沿山路走到最远的山顶

- 来源: sy-styles-20 styles/04-lineart（MIT, 肖雄）
- 层次: sy 实用风格
- 技术: Canvas 2D（每根线都由公式算出）
- wv 可移植性: 直接可移植（polyline + lighter 合成，全是 2D 手法）

## 核心手法

- 地形：5 阶脊状噪声 (1-|noise3|)²（f 从 0.055 每阶 ×2.05），远峰 exp 高斯 (8.5,34) ×9.5 在画面右三分之一，谷地压制，高度 ×min(1,z/5) 近处压平。
- 山脊网格：NR=76 排 × NP=140 点，行距 ROWZ=3+52*(i/75)^1.35（透视近疏远密），宽 XR=46，高度预烘焙进 HGT。
- 流线：900 根（76 排×12）×60 段，curl 场=noise3 有限差分（s=0.0016、e=1.2、z=t*0.22 缓慢演化），步长 10px，加恒定风 (0.55,-0.08)。
- 变形：每根线按 (i%12)*0.035+行深度*1.1 错峰 inOutCubic，从流线路径 lerp 到山脊折线（横向偏移 (k-5.5)*6*(1-m) 散开再收拢）；合成用 'lighter' 让金线叠亮，山体实心后切回 source-over。
- 实心化：4.0-5.6s 山脊下方填 rgba(7,11,23) 遮挡色，线景变实心风景；颜色按深度从 GOLD [232,196,128] 向蓝灰 lerp（近亮远淡）。
- 太阳：4.6-8.2s 从山脊后升起，线框太阳=14 圈同心圆（R=165、间距 9）+ 径向 halo。
- 走山的光：120 个采样点沿地形（5 点平均高度+0.1 抬升）从近到远，3 遍描边叠光 [9px/0.06, 4px/0.16, 1.6px/0.95]，头部 radial glow，抵达时 flare=exp(-(t-8.1)*2.2)。
- 收尾：暗角 + 640×360 颗粒画布按帧滚动（alpha 14，固定噪点对子帧采样安全）。
- wv 对应: 手绘管线（canvas strokes: curve/jitter/smooth）——polyline + 'lighter'，直接可移植

## 母题动画与钩子

- 0-2.1s 丝绸飘（逐段生长 outCubic），2.1-3.6s+ 错峰排成山脊，4.0-5.6s 变实心；钩子在 5.4-8.1s：一束亮光沿山路走到最远山顶并 flare，标题「远方」6.4-7.6s 随字距收拢落定（ls=lerp(0.5,0.32)*150）。
- cues: swell 0.2 / whoosh 2.6 / chime 4.4 / pen 5.6 / sparkle 7.4。

## 签名转场/镜头

- 镜头向前滑行（z -6→1.5、y 7.2→6.2、pitch 0.2→0.15，F=980，inOutSine 2.2-10s）。
