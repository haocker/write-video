# doodle-explain · 简笔画解说 · 像 PPT 一样：先把这一页的图画出来，再给文字

> **本卡只给框架**：所有数值、配色、笔触、版式都是空槽，每支片现场定。卡里出现任何"具体画什么"都只是示意，不要照搬。
> 参考实现（不是模板）：`examples/style-ports/doodle-explain/film.py`（《简笔画蒙娜丽莎》46s 五页图解）。

- 层次: 实用风格（讲解/图解/科普）
- 技术: 2D 图元直绘（笔画生长 + 手写标注），无 3D 依赖
- wv 可移植性: 直接可写——图元直绘 + 文字即可，无需移植

## 定位

一句话：**用笔画建立空间模型，用文字解释这个模型。**

适合：概念拆解、流程说明、数据图解、产品逻辑、教程分步。
不适合：需要照片质感、复杂光影、真实人脸或精细机械的题材。

判断标准：如果把画面换成"一张静态示意图 + 几行字"，信息还完整吗？完整就适合本卡。

## 画面分层（每层只负责一件事）

| 层 | 职责 | 自由度高 | 判断它是否合格 |
|---|---|---|---|
| 纸面层 | 提供"这是被画出来的东西"的语境 | 极高（白板/纸/黑板/方格纸…） | 不能与笔画抢注意力 |
| 图示层 | 本页的论点本体（结构、流程、关系） | 高 | 只留主结构，细节靠标注补 |
| 标注层 | 文字、编号、名称 | 高 | 位置服务阅读顺序，不装饰 |
| 强调层 | 圈、下划线、箭头、高亮、划掉 | 极高 | 只在"这一句最重要"时出现 |
| 光标层 | 笔尖/手/游标，显示"正在画" | 可选 | 出现即有代价：观众会盯着它 |

视觉重量只留三级：**主结构 > 标注 > 强调**。再多一级，观众就不知道先看哪。

## 编排语法（页是最小单位）

一页的生命周期：

```
出纸/留白 → 画主结构（最少笔数） → 补细节 → 写标注 → 加强调 → 停 → 换页
```

四条硬规则：

1. **先画后说**：文字永远晚于它解释的那个图形出现。同时出现＝失去讲解感，退化成一张静态 PPT。
2. **一页一论点**：本页所有笔画都为这一个论点服务；出现第二个论点就换页。
3. **停顿是参数不是浪费**：画完到写字之间的空拍，决定观众有没有时间"看懂"。空拍长度按信息密度给，不按总时长均分。
4. **换页必须显式**：清空重画 / 翻页 / 推镜 / 划掉重来，选一种并保持全片一致。

页内的注意力顺序用"笔"引导：笔尖经过 → 圈住 → 下划线 → 箭头指向，一步只做一件事。

## 空槽清单（每支片现定，不预设值）

| 槽位 | 要定的问题 | 不定的后果 |
|---|---|---|
| 笔 | 粗细/圆头或毛边/单色或双色 | 质感与题材气质冲突 |
| 纸 | 白板 / 纸 / 黑板 / 方格 / 牛皮 | 对比度失控，线看不清 |
| 手 | 画不画手，还是让笔自己动 | 两种情况混用会显得随意 |
| 版式 | 图左文右 / 图中说明在下 / 引线标注 | 阅读顺序混乱 |
| 页数与时长 | 每页停留多久、全片几页 | 信息节奏被总时长反向决定 |
| 强调手法 | 圈 / 划线 / 高亮 / 划掉 / 盖章 | 全用等于都不用 |
| 换页方式 | 清空 / 翻页 / 推镜 / 擦除 | 观众丢失"这是一页"的感知 |
| 是否编号 | 步骤编号或进度提示 | 长片里观众不知道还剩多少 |

## 结构约束（必须成立，与做法无关）

- 笔画要能"生长"：按路径长度截断，不能整笔闪现，否则失去"被画出来"的因果关系。
- 抖动必须按固定节拍重掷（重掷频率与帧率对齐）；节拍不固定会糊成噪点，太快则失去手绘感。
- 文字必须与图形共用同一套"手"的抖动逻辑，否则字像贴上去的。
- 标注/文字不得压在笔画上：留白至少半个行高。
- 半透明线条必须与底色预混合后再画；直接叠 alpha 会变成实心深色（PIL 系画布尤其如此）。
- 一页内出现两个以上"最重"元素时，必有一个被降级。

## 自检（交付前逐条过）

1. 静帧检验：抽最后一帧，像一张能独立读懂的示意图吗？
2. 顺序检验：随机抽一帧，能不能判断"它是先画图后写字"？
3. 密度检验：把文字全去掉，图的骨架还能传达论点吗？
4. 节奏检验：有没有一页是"画完立刻写字"的？有就加空拍。
5. 一致性检验：换页方式、笔、纸三者全片是否统一？

## wv 对应

- 图元直绘：`c.lines(pts, width, jitter=…, seed=…)` 自带手绘抖动与压感；生长按弧长截断后喂给它。
- 抖动节拍：`BOIL = int(t * 频率)` 参与 seed，保证同一拍内所有笔画抖动一致。
- 手写字：逐字绘制 + 每字独立位移/轻微旋转；CJK 用 `wv.fonts.load("sans_bold"…)`。
- 换页：一页一个 `scene`，页面之间用 cut；页内"擦除"要么用底色矩形盖，要么重画。
- 纸纹：`texture` 系列或极淡噪声；纸纹不能盖住笔画边缘。
