# ghibli · 1988 吉卜力式手绘水彩 · 透明叠色水痕边＋赛璐璐月牙影的材料层

- 来源: huashu 风格配方 25_ghibli.md
- 层次: 材料层
- 质量: ★★ ；短板: 人物不如背景（扁平矢量感，可加吉卜力式发丝高光块）

## 核心渲染器与手法

1. **`deform(pts, depth, amp, r)` 中点位移**：每轮在每条边中点沿法向推一个近似高斯量（3 个均匀数相加），幅度和边长成比例（min(1, len/80)），每轮 amp×0.6。
2. **`wash(g, pts, color, {layers, alpha, amp, seed, edge, blend, fill})`**：先 deform 3 轮得基形；每层再 deform 2 轮，multiply 低 α 填充（透明颜料叠色），并以 α=edge 描一圈 1.6px 同色边——描边逐层叠加就是颜料在边缘沉积的**水痕边**。fill 可以传渐变（天空、墙）。
3. **常用参数**：大面积墙 layers 5、α 0.4、amp 12；色晕 layers 3、α 0.045、amp 40（大幅变形）；木板 layers 3、α 0.5、amp 3、edge 0.14；不透明的白（窗框、桌布、云）blend:'source-over'、α 0.9–0.95。
4. **墙的层次**：径向渐变洗染（窗边亮 `#fbf3e0` → 角落 `#dcc49a`）＋28 块大幅变形的透明色晕（暖黄、粉、蓝灰、浅绿交替）＋两角暗晕；护墙板和地板逐块换色调洗染；最后 multiply α 0.3 叠一层高频纸纹颗粒。坑：色晕 α 0.07×4 层、颗粒 multiply 0.5 时墙面像发霉的旧羊皮纸——色晕 α 降到 0.045×3 层，渐变整体提亮一档。坑：第一版用两个矩形 wash 拼墙（右侧更暗），x≈1100 出现硬接缝——暗部要用大幅变形的多边形（amp 60）。
5. **精灵缓存**：云＝白色不透明圆团（16 个 puff，wash 画边）＋source-atop 叠底部蓝灰渐变；大樟树同法，绕树根转 ±0.025rad。
6. **赛璐璐角色 `cel(c, p, base, shade, dx, dy)`**：先整块填阴影色，再在 clip(p) 里把自身朝光平移 (−dx, −dy) 后填基色，只剩背光侧一道月牙阴影；最后描 2.4px 暖褐线 `#4a3428`。一个函数就是吉卜力式两色赛璐璐。
7. **角色水彩化（审片「人物不像」的修法）**：角色先画进离屏 L；另起纹理层 M（纸纹颗粒 α 0.8 ＋40 块透明色晕 charBloom，α 0.1、amp 16），M 用 destination-in 按 L 的剪影裁掉，再以 multiply 叠回画面；线色从 `#4a3428` 调软到 `#6a4a38`。

wv 对应: 已移植渲染器 watercolor（跨 pass 叠色）＋ texture(paper)；cel 月牙影用图元直绘（阴影块＋朝光平移 clip）；wash 的 edge 水痕边参数需在 watercolor 里补

## 母题动作

- 白纱窗帘（两幅）：下摆鼓起 `q²·(90 + 70·gust)`，gust = 0.55 + 0.45·sin(3.2lt + 相位)，叠 `sin(7lt + 6q)` 小波纹；3 层半透明 wash 固定种子，边缘不沸腾。坑：审片说不飘——gust 频率 3.2 → 5.4，鼓起改 `q²·(60 + 150·gust)`
- 窗外 360 根草叶：`wind = 0.5 + 0.5·sin(3.1t − 0.018x)`，相位沿 x 推进＝一道风浪扫过草坡
- 云飘 22–30px/s；树冠轻摇
- 墙上 34 个 komorebi 光斑：screen 暖黄径向渐变，位置用 noise 漂，亮度 `sin(5t + 1.7i)` 闪
- 雏菊点头；少女长发吹向右后（7 点 smooth，wind 推动）；蝴蝶结飘带抖动；桌布垂边摆动
