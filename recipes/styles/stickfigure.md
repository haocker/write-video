# stickfigure · 火柴人动画 · 用最少的线讲故事：世界有规则，角色有反应，反转有依据

> **本卡只给框架**：不规定角色长什么样、不规定情节、不规定配色与节奏数值。所有"空槽"每支片现场定。
> 参考实现（不是模板）：`examples/style-ports/stickfigure/film.py`（《最后一格》30s 三幕）。

- 层次: 实用风格（叙事短片/寓言/概念片/科普小剧场）
- 技术: 2D 图元直绘（骨架摆姿 + 逐笔生长 + 整幅变换），无 3D 依赖
- wv 可移植性: 直接可写——骨架、笔画、镜头全是 2D 代码

## 定位

一句话：**细节为零，所以表演、规则和反转必须承担全部信息量。**

适合：概念反转、寓言、荒诞喜剧、流程戏剧化、品牌短片、需要大量镜头的叙事。
不适合：需要细腻情绪、精细手部动作、复杂打斗、写实质感的题材。

判断标准：如果你把角色换成"两根线加一个圆"，故事还成立吗？成立就适合本卡。

## 画面分层（每层负责一件事）

| 层 | 职责 | 关键问题 |
|---|---|---|
| 世界层 | 定义"什么是硬的"（地面、墙、边界、重力）与"什么是软的"（风、光、影子） | 规则在前段被**演示**过一次，而不是被台词说出来 |
| 角色层 | 骨架 + **一个**身份记号 | 剪影能不能认出是同一个人 |
| 表演层 | 姿态曲线（关键帧 + 缓动），不是逐帧画 | 重量感来自膝/肘与接触帧 |
| 表情层 | 少数几个符号位：眼、嘴、? ! 汗滴、震动线 | 只在需要读者确认情绪时出现 |
| 镜头层 | 推 / 拉 / 摇 / 切 / 整幅缩放 | 镜头跟着"角色的看"走 |
| 痕迹层 | 脚印、尘土、灰痕、擦痕、残留物 | 世界记得发生过什么 |
| 声层 | 动作声与动作同帧；音乐只做情绪底 | 关掉声音，动作还读得懂吗 |

## 编排语法（三拍循环）

全片由若干"动作 → 反应 → 反转"组成：

1. **动作**：角色做一件有明确目标的事（观众能一句话说出他想干什么）。
2. **反应**：世界或角色给出可见后果（痕迹层在这里起作用）。
3. **反转**：用**前面已经建立过的规则**推翻预期——不能凭空出现新能力、新角色、新道具。

三条时间规则：

- 每 3-5 秒必须有一次**状态变化**（位置、姿态、画面层级、信息量），否则观众走神。
- 反转前必须有一段"平静"作对比；没有平静就没有反转。
- 结尾留一个**未闭合的画面**（角色看着观众 / 世界还在动），比解释清楚更有余味。

镜头跟着注意力：**角色看哪里，镜头给哪里**；角色看不到的东西，观众可以先看到（这是信息差的来源）。

## 空槽清单（每支片现定，不预设值）

| 槽位 | 要定的问题 |
|---|---|
| 世界载体 | 纸面 / 桌面 / 画框 / 房间 / 屏幕——世界是"被画出来的"还是"真实存在"的 |
| 规则类型 | 空间类（边界、重力、通路）/ 道具类（一个东西有特殊用途）/ 时间类（循环、倒放）/ 元层类（角色知道自己在画里） |
| 角色记号 | 帽子 / 围巾 / 体型比例 / 笔色 / 眼睛形状——只选一个 |
| 角色数量 | 1 人（独白/荒诞）/ 2 人（对话/对立）/ 群体（同质化讽刺） |
| 夸张度 | 顺滑 / 一拍二 / 一拍三；四肢极限角度 |
| 镜头语言 | 固定机位 / 跟随 / 整页拉远 / 硬切为主 |
| 痕迹策略 | 什么都不留（干净） / 关键动作才留（强调） / 一直累积（世界在变质） |
| 声 | 只有动作声 / 动作声 + 环境底 / 全配乐 + 音效点 |

## 结构约束（必须成立，与做法无关）

- **四肢必须两段**（有膝、有肘）。单段直棍读不出重量与意图。
- **每帧必须有接触帧**：站立时最低点贴地，落地瞬间不许悬空；否则人物像漂浮的贴纸。
- **多角色同框必须分层**：靠线宽、明度或层级（前景实、背景淡）区分；同一线宽三人以上必糊。
- **变形不破比例**：压扁拉伸时头身比与四肢长度保持可辨认，否则观众不认为是同一个角色。
- **擦除/消失要留证据**：灰痕、碎屑、残留线条，否则读者会以为是渲染错误。
- **反转必须由已建立规则推出**：新规则只能在反转之前建立，不能在反转时登场。
- **半透明叠加须预混合**：直接叠 alpha 在 PIL 系画布上会变成实心深色。

## 自检（交付前逐条过）

1. 静音检验：关掉声音看一遍，动作与因果还读得懂吗？
2. 剪影检验：把每一帧压成纯黑剪影，能认出角色与姿态吗？
3. 规则检验：把反转单独拎出来，它用到的规则在第几秒建立过？
4. 冗余检验：删掉任意 10%，故事还成立吗？成立就说明该删。
5. 痕迹检验：关键动作后，画面有没有"世界记得"的证据？

## wv 对应

- 骨架摆姿：关节角 → 世界坐标（髋/肩/头 + 两段四肢），姿态参数化为"角度表"，关键帧插值 + 缓动。
- 逐笔生长：按弧长截断 + `c.lines(jitter=…, seed=…)`；生长速度本身就是表演（快＝急，慢＝迟疑）。
- 镜头：整幅变换（缩放 + 平移）用统一的世界→屏幕函数，所有绘制都走它；拉远/推近就是参数曲线。
- 痕迹层：贴图式的淡痕（预生成模糊 sprite）或直接画短线；淡入淡出用预混合色，不用 alpha。
- 元层（如有）：页面/画框本身也走同一套坐标系，缩放它即可完成"拉远看到整页"的反转。
- 声：动作关键帧处打 sfx，同帧不可延后；音乐铺情绪，不跟随动作节拍。
