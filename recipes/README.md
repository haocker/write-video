# 视频创作配方卡

每类片一张卡：**踩完坑之后的可复现配方**——参数、坑、返修记录三位一体，下次照卡直出。

## 什么时候写卡

- 每做完一类片（宣传片/片头/数据介绍/动效动画/游戏视频/故事短片...），审片通过、v2 返修收尾后，把实际跑通的配方沉淀成一张卡。
- 写卡时只记"怎么做的、为什么这么定、踩过什么坑"——分镜逐字文案留在项目的 film.py 里，卡里记骨架与配方。

## 什么时候读卡

- 新片先查有没有同类配方卡：有 → 照卡起步（骨架/参数/坑直接复用，只换内容），无 → 按 planning.md 走策划流程，做完回头补卡。

## 卡的结构（参考 huashu 风格配方）

| 节 | 内容 |
|---|---|
| 标题行 | `编号_类型名 · 一句话定位（参考片：xxx）` |
| 定位 | 目的 / 观众 / 时长与规格 / 风格 |
| 分镜骨架 | 节拍表：时间 × 场景 × 内容 × 招牌镜头 |
| 画面配方 | 每场景：声明元素 vs 自绘的分工、具体参数（cell/宽度/色板/坐标） |
| 动效配方 | 入场/转场预设、母题动画的参数公式 |
| 声音配方 | 配乐骨架（BPM/调式/动机/和声进行/配器，遵循 compose.md 旋律写法六约束）+ 音效时刻表 + 配音 |
| 踩过的坑 | 嵌在配方里 + 集中列出（对应 compose.md 常见坑的实例化） |
| v2 返修 | 审片发现的问题与修法（帧差/清晰度/节奏的具体数据） |
